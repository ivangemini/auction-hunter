# Auction Hunter

Browser-first auction, appraisal, restoration and collection game for Yandex Games.

## Stack

- Phaser 4
- TypeScript
- Vite
- Yandex Games SDK

## Development

```bash
npm install
npm run dev
```

## Quality gates

```bash
npm run typecheck
npm run build
```

The initial vertical slice focuses on the core loop: bid on a storage lot, reveal items, appraise them, then sell or keep them in the collection.
